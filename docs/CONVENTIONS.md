# Repository and code conventions

Part of the D0 deliverable. Items marked **DECISION** must be closed in M0:
each is resolved with a one-sentence rationale, or with an ADR if it is not obvious.

## Git

- Main branch `main`, protected: pull request required, green CI, one review approved by the other (four-eyes rule). Review within 48 hours.
- One branch per issue: `area/short-description`, for example `ctrl/dpwm-pipeline`.
- Commit messages: `area: action`, for example `ctrl/dpwm: register the comparison one cycle earlier`.
- Areas: `ctrl`, `plant`, `model`, `sw`, `cosim`, `hil`, `docs`, `ci`, `tools`.
- No generated files in Git: bitstreams, Vivado projects, simulation folders. Acceptance-test bitstreams are attached to tagged releases.

## RTL

- **DECISION (D):** dialect. Pure Verilog-2005 or the SystemVerilog subset accepted by Yosys (CTL-01)? What do you actually need from SV, and what does it cost you in portability across Yosys, Verilator, Icarus, and Vivado?
- **DECISION (D):** reset. Synchronous or asynchronous, active-high or active-low, and which registers need it. Reread the client's note in § 14.1 about the remaining critical path before answering.
- One module per file, file name equal to the module name.
- Clock-domain suffix on every signal where there is more than one domain: `_sys`, `_sclk`.
- No magic numbers: parameters from `localparam` with the unit in the name (`DEADTIME_NS`, `TSW_CYCLES`) or from constants generated by `docs/icd/regs.yaml`.
- `default_nettype none` at the top of every file.
- Device primitives (`SB_PLL40_*`, `SB_IO`, `IDDR`, `ODDR`...) only in `*/board/`. In `*/rtl/` only portable logic, simulatable and lintable on its own.

## Fixed point

- `Qm.n` notation: m integer bits including sign, n fractional bits. The format of every signal is written in the code and in the documentation.
- Round-to-nearest where truncation would introduce drift (integrators).
- Saturating arithmetic on the outputs of every stage, with a readable saturation counter.

## Python

- Python 3.12, `ruff` for style.
- Units in the names: `t_dead_ns`, `i_load_a`, `v_out_v`.
- Bit-true models with Python integers and explicit masks: no `float` in the path.
- The bit-true model of a module is written by whoever did not write its RTL (§ 20.2).

## Documentation

- Every folder has a short README.
- Non-obvious decisions go in `docs/adr/NNNN-title.md` (template: `0000-template.md`).
