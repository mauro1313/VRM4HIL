# plant

HIL plant on PYNQ-Z1 (pipeline and timing: D; equations and validation: A).

- `rtl/`: portable Verilog core, co-simulatable with Verilator
- `board/`: wrapper with IDDR/ODDR, clock buffers, `.xdc`
- `hw/build.tcl`: Vivado project generated by script, no project files in Git
- `tb/`: cocotb testbenches
